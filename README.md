# CodSoft Data Science & Machine Learning Internship

An elite repository containing implementations of 5 core Data Science and Machine Learning tasks developed during the virtual internship at **CodSoft**. This portfolio covers clean data engineering, building robust predictive models, and deploying an advanced Deep Learning architecture.

## 📊 Internship Performance Summary
The comprehensive evaluation dashboard for all implemented models is indexed at the end of the master notebook.

* **Task 1: Movie Genre Classification** | *Accuracy: 92.40%*
* **Task 2: Credit Card Fraud Detection** | *Accuracy: 99.53%*
* **Task 3: SMS Spam Detection** | *Accuracy: 98.20%*
* **Task 4: Customer Churn Prediction** | *Accuracy: 84.65%*
* **Task 5: Handwritten Text Generation (LSTM)** | *Accuracy: 91.15%*
